# 月历组件

- 分类：日期日历（calendar）
- 分组：基础控件
- 风格标签：桌面端、日期、日历、antd、iOS、Google、Dark、Awwwards、支付宝、Atlassian、便当盒布局、材料、黏土、玻璃拟态、新粗野主义、Vercel、GitHub、Notion、暗黑模式、扁平
- 页面：https://ui.vavagent.com/v/calendar-001/

## 设计说明

设计月历组件：
- 白底 1px #e5e7eb 边框，圆角 8px，padding 16px
- 顶部：月份标题 14px 加粗 + 左右切换箭头
- 星期行：11px 灰色，日/一/二/三/四/五/六
- 日期格子：12px，padding 6px，居中
- 选中日期：蓝色 #2563eb 底白字，圆角 4px
- 整体风格：通用日期选择器
