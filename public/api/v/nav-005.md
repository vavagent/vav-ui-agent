# 小红书底部 Tab 栏

- 分类：导航菜单（nav）
- 分组：导航与结构
- 风格标签：移动端、App、Tab、小红书、antd、Linear、Vercel、iOS、Stripe、shadcn、Bootstrap、抖音、Skeuomorphism、Glassmorphism、复古像素、玻璃拟态、新拟态、新粗野主义
- 页面：https://ui.vavagent.com/v/nav-005/

## 设计说明

设计一个小红书风格的底部 Tab 栏：
- 白底，顶部 1px #f0f0f0 分割线，底部留 20px 安全区
- 5 个入口：首页 / 发现 / 中间发布 / 消息 / 我
- 未选中：灰色 #666，图标 22×22 圆角方块 #ddd
- 选中：品牌红 #ff2442，图标填充红色，文字加粗
- 中间发布按钮：46×32 圆角 8px，红粉渐变，白色 + 号，比其他 tab 大
- 整体风格：小红书首页底部导航
