# Apple 风格全屏菜单

- 分类：导航菜单（nav）
- 分组：导航与结构
- 风格标签：桌面端、品牌、创意、Apple、antd、Linear、Vercel、iOS、Stripe、shadcn、Vuetify、Skeuomorphism、飞书、京东、材料、新粗野主义、赛博朋克、极简
- 页面：https://ui.vavagent.com/v/nav-007/

## 设计说明

设计一个 Apple 官网风格的全屏覆盖菜单：
- 点击汉堡后纯黑全屏（#000），无圆角
- 菜单项垂直居中排列，24px 字重 500，白色，间距 6px
- 无图标、无分割线、无装饰
- 底部可放一行小号灰色版权信息
- 过渡动画：淡入 + 轻微上移
- 整体风格：apple.com 产品页全屏菜单，极简、高级
