# 表单弹窗

- 分类：弹窗/抽屉（modal）
- 分组：反馈与弹层
- 风格标签：弹窗、表单、编辑、Linear、Vercel、antd、扁平、暗黑模式、极简
- 页面：https://ui.vavagent.com/v/modal-006/

## 设计说明

设计表单弹窗：
- 标题 + 输入框 + 描述 + 按钮
- 取消（白底灰边）+ 保存（蓝底白字）
- 整体风格：编辑项目弹窗

## 一句话描述

表单弹窗：带输入框弹窗 风格 弹窗 / 表单 / 编辑 / Linear
