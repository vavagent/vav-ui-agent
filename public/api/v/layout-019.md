# 页脚贴底布局

- 分类：布局栅格（layout）
- 分组：导航与结构
- 风格标签：布局、页脚、贴底、antd、Linear、Material、暗黑模式、极简、Tailwind
- 页面：https://ui.vavagent.com/v/layout-019/

## 设计说明

设计页脚贴底布局，主内容自适应，页脚固定在底部。

## 一句话描述

页脚贴底布局：Sticky Footer 风格 布局 / 页脚 / 贴底 / antd

## 改造现有页面用的提示词

```text
把现有页面里的「页脚贴底布局」改成这个观感，只改样式，不重写。

技术栈：按我项目现有的（Vue / Quasar 或 React / Tailwind 均可），不要升级版本，不要引入新依赖。

参照描述：
设计页脚贴底布局，主内容自适应，页脚固定在底部。

约束：
1. props 名称、数据字段、组件层级一律不动，只调整布局 / 间距 / 字号 / 颜色 / 圆角 / 阴影
2. 需要动效时用项目已有能力降级实现，不新增动画库
3. 先给 2-3 个方向（每个方向改了什么、风险在哪），我确认后再出代码
4. 出代码时给完整单文件版本，不要给 diff
验收：功能不变，构建能过。风格关键词：布局 / 页脚 / 贴底 / antd / Linear / Material
```
