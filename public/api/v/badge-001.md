- 分类：徽标 Badge（badge）
- 分组：基础控件
- 风格标签：通知、Badge、通用、antd、iOS、小红书、Glassmorphism、Dribbble、抖音、Element、插画、材料、新粗野主义、赛博朋克、拟物、Notion、暗黑模式、Vercel、Linear
- 页面：https://ui.vavagent.com/v/badge-001/

## 设计说明

设计数字徽标：
- 绝对定位在图标右上角
- 红色 #ef4444 圆点，白字 10px
- 最小宽度 18px，高度 18px，圆角 9px（胶囊形）
- 超过 99 显示"99+"
- 整体风格：通用通知角标

## 一句话描述

数字徽标：红色圆点 + 数字。 风格 通知 / Badge / 通用 / antd
