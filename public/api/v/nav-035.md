# Linear 首页宫格入口

- 分类：导航菜单（nav）
- 分组：导航与结构
- 风格标签：桌面端、首页、卡片、Linear、antd、Vercel、iOS、Stripe、shadcn、微信、Awwwards、Shopify、Neumorphism、拟物、扁平、黏土、赛博朋克
- 页面：https://ui.vavagent.com/v/nav-035/

## 设计说明

设计一个 Linear 风格的首页宫格入口：
- 3 列网格，卡片白底，1px #e5e7eb 边框，圆角 8px
- 每个卡片：padding 16px，顶部 28×28 圆角图标（品牌色）
- 图标下方：14px 加粗标题 + 12px 灰色描述
- 卡片间距 12px，外层浅灰底 #fafbfc
- 整体风格：Linear 工作区首页
