- 分类：布局栅格（layout）
- 分组：导航与结构
- 风格标签：桌面端、官网、居中、Vercel、Linear、antd、Shopify、京东、Fluent、材料、复古像素、拟物、便当盒布局、黏土、暗黑模式、Stripe、Notion、瑞士国际主义、iOS
- 页面：https://ui.vavagent.com/v/layout-003/

## 设计说明

设计居中内容区布局：
- 内容最大宽度 600px，margin 0 auto
- 上下 padding 40px
- 整体风格：博客/文档站文章页
