# 抽屉叠加布局

- 分类：布局栅格（layout）
- 分组：导航与结构
- 风格标签：布局、抽屉、叠加、Stripe、Linear、玻璃拟态、小红书、Notion、暗黑模式、Tailwind、极简、Vercel
- 页面：https://ui.vavagent.com/v/layout-017/

## 设计说明

设计抽屉叠加布局，主内容区右侧浮层抽屉面板。

## 一句话描述

抽屉叠加布局：主区+浮层抽屉 风格 布局 / 抽屉 / 叠加 / Stripe

## 改造现有页面用的提示词

```text
把现有页面里的「抽屉叠加布局」改成这个观感，只改样式，不重写。

技术栈：按我项目现有的（Vue / Quasar 或 React / Tailwind 均可），不要升级版本，不要引入新依赖。

参照描述：
设计抽屉叠加布局，主内容区右侧浮层抽屉面板。

约束：
1. props 名称、数据字段、组件层级一律不动，只调整布局 / 间距 / 字号 / 颜色 / 圆角 / 阴影
2. 需要动效时用项目已有能力降级实现，不新增动画库
3. 先给 2-3 个方向（每个方向改了什么、风险在哪），我确认后再出代码
4. 出代码时给完整单文件版本，不要给 diff
验收：功能不变，构建能过。风格关键词：布局 / 抽屉 / 叠加 / Stripe / Linear / 玻璃拟态
```
