# 登录表单

- 分类：表单输入（form）
- 分组：基础控件
- 风格标签：桌面端、认证、表单、antd、iOS、Material、Linear、微信、Vuetify、Airbnb、材料、3D立体、黏土、极简、暗黑模式
- 页面：https://ui.vavagent.com/v/form-004/

## 设计说明

设计一个标准登录表单：
- 标题 20px 加粗，下方间距 20px
- 每个字段：标签 13px + 输入框（1px #d1d5db 边框，圆角 6px，padding 8px 12px）
- 字段间距 16px，提交按钮全宽黑底白字
- 底部注册链接 13px 灰色，"注册"蓝色 #007AFF
- 整体风格：通用 SaaS 登录页

## 一句话描述

登录表单：邮箱 + 密码 + 提交按钮，垂直排列。 风格 桌面端 / 认证 / 表单 / antd
