# 居中确认弹窗

- 分类：弹窗/抽屉（modal）
- 分组：反馈与弹层
- 风格标签：移动端、确认、弹窗、antd、iOS、小红书、微信、京东、Bootstrap、飞书、暗黑模式、材料、拟物、扁平、玻璃拟态、Linear
- 页面：https://ui.vavagent.com/v/modal-003/

## 设计说明

设计移动端居中确认弹窗：
- 半透明黑底 rgba(0,0,0,.5)
- 卡片白底圆角 14px，padding 24px，居中
- 顶部 48px 圆形警告图标（浅红底）
- 标题 16px 加粗 + 描述 13px 灰色
- 底部两个按钮：取消（灰底）+ 确认（红色 #ff2442）
- 整体风格：iOS Alert / 小红书确认弹窗

## 一句话描述

居中确认弹窗：标题 + 图标 + 按钮。 风格 移动端 / 确认 / 弹窗 / antd
