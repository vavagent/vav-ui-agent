# 侧边滑出抽屉

- 分类：弹窗/抽屉（modal）
- 分组：反馈与弹层
- 风格标签：桌面端、抽屉、后台、antd、iOS、小红书、Atlassian、Awwwards、Neumorphism、拟物、玻璃拟态、插画、便当盒布局、黏土、Stripe、GitHub、极简、Tailwind
- 页面：https://ui.vavagent.com/v/modal-004/

## 设计说明

设计桌面端侧边抽屉：
- 从右侧滑出，宽 280px，全高
- 白底，左侧阴影 -4px 0 16px rgba(0,0,0,.1)
- 顶部标题 16px 加粗 + 关闭按钮 ✕
- 整体风格：后台详情抽屉
