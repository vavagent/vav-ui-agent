# GitHub 仓库面包屑

- 分类：面包屑/步骤（breadcrumb）
- 分组：导航与结构
- 风格标签：桌面端、开发者、面包屑、antd、GitHub、Linear、Bootstrap、Airbnb、Tailwind、Neumorphism、插画、3D立体、拟物、极简、新粗野主义、玻璃拟态
- 页面：https://ui.vavagent.com/v/breadcrumb-001/

## 设计说明

设计 GitHub 风格面包屑：
- 白底 padding 16px 24px，底部 1px #e5e7eb 分割线
- 格式：用户名 / 仓库名，蓝色 #0969da，仓库名加粗
- 右侧分支按钮：圆角 20px，浅灰底 #f6f8fa，边框 #d0d7de
- 整体风格：github.com 仓库页头部
