# Vercel 毛玻璃收缩导航

- 分类：导航菜单（nav）
- 分组：导航与结构
- 风格标签：桌面端、官网、动效、Vercel、antd、Linear、iOS、Stripe、shadcn、Awwwards、支付宝、Element、拟物、扁平、复古像素、3D立体、暗黑模式
- 页面：https://ui.vavagent.com/v/nav-010/

## 设计说明

设计一个 Vercel 风格的毛玻璃顶部导航：
- 背景 rgba(255,255,255,.8) + backdrop-filter: blur(12px)
- 高度 56px，底部 1px 半透明分割线 rgba(0,0,0,.06)
- 左侧：黑色三角 Logo + "Vercel" 加粗 14px
- 中间菜单 14px，灰色 #666
- 右侧黑色 CTA 按钮（圆角 6px，padding 6px 14px）
- 滚动前透明，滚动后浮现毛玻璃效果
- 整体风格：vercel.com 官网顶栏
