# 复选框

- 分类：表单输入（form）
- 分组：基础控件
- 风格标签：桌面端、多选、表单、antd、iOS、Material、Linear、抖音、Element、Airbnb、材料、极简、3D立体、赛博朋克、Vercel
- 页面：https://ui.vavagent.com/v/form-006/

## 设计说明

设计一组复选框：
- 勾选框 18×18px，圆角 4px
- 选中态：#007AFF 蓝底 + 白色 ✓
- 未选中：1.5px #d1d5db 边框
- 标签 14px，间距 8px
- 整体风格：通用表单复选框

## 一句话描述

复选框：带勾选框 + 标签，支持半选态。 风格 桌面端 / 多选 / 表单 / antd
