# shadcn/ui 风格 Tabs

- 分类：导航菜单（nav）
- 分组：导航与结构
- 风格标签：桌面端、UI库、极简、shadcn、antd、Linear、Vercel、iOS、Stripe、Vuetify、Shopify、Glassmorphism、玻璃拟态、便当盒布局、扁平、拟物、新粗野主义
- 页面：https://ui.vavagent.com/v/nav-008/

## 设计说明

设计一个 shadcn/ui 风格的 Tabs 组件：
- 外层浅灰容器 #f5f5f5，padding 4px，圆角 8px
- 每个 tab：padding 6px 14px，圆角 6px，13px 文字
- 选中态：白底 + 轻微阴影 0 1px 2px rgba(0,0,0,.1) + 黑色文字
- 未选中：透明底 + #737373 文字
- 间距 2px，紧凑
- 整体风格：shadcn/ui 的 Tabs demo，Radix 风格
