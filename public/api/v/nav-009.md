# GitHub 仓库面包屑

- 分类：导航菜单（nav）
- 分组：导航与结构
- 风格标签：桌面端、开发者、面包屑、GitHub、antd、Linear、Vercel、iOS、Stripe、shadcn、Vuetify、Glassmorphism、Tailwind、新粗野主义、插画、扁平、赛博朋克
- 页面：https://ui.vavagent.com/v/nav-009/

## 设计说明

设计一个 GitHub 风格的仓库面包屑：
- 白底，padding 16px 24px，底部 1px #e5e7eb 分割线
- 格式：用户名 / 仓库名，用户名和仓库名用蓝色 #0969da
- 仓库名加粗，分隔符灰色 #6e7781
- 右侧一个分支切换按钮：圆角 20px，浅灰底 #f6f8fa，边框 #d0d7de，带分支图标
- 整体风格：github.com 仓库页头部

## 一句话描述

GitHub 仓库面包屑：带仓库图标、分支切换、相对时间。 风格 桌面端 / 开发者 / 面包屑 / GitHub
