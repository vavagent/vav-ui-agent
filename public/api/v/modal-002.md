# iOS 底部抽屉

- 分类：弹窗/抽屉（modal）
- 分组：反馈与弹层
- 风格标签：移动端、iOS、抽屉、antd、小红书、Bootstrap、Neumorphism、支付宝、Shopify、扁平、拟物、复古像素、3D立体、插画、暗黑模式、Linear
- 页面：https://ui.vavagent.com/v/modal-002/

## 设计说明

设计 iOS 风格底部抽屉：
- 从底部滑出，顶部圆角 16px
- 顶部拖拽指示条：36×4px 灰色圆角
- 标题 16px 加粗 + 一行分享图标（48×48 圆角方块）
- 底部安全区 padding 32px
- 整体风格：iOS 分享面板
