# iOS 风格移动端导航栏

- 分类：导航菜单（nav）
- 分组：导航与结构
- 风格标签：移动端、iOS、App、顶栏、antd、Linear、Vercel、Stripe、shadcn、Vuetify、微信、抖音、Fluent、拟物、新拟态、暗黑模式、扁平、材料
- 页面：https://ui.vavagent.com/v/nav-004/

## 设计说明

设计一个 iOS 风格的移动端导航栏：
- 白底，底部 0.5px #c6c6c8 分割线
- 顶部状态栏显示时间 9:41（11px 灰色）
- 下方大标题 28px 加粗左对齐（SF Pro / PingFang）
- 右侧一个 32×32 圆形浅灰按钮（#f0f0f0），里面 + 号
- 整体风格：iOS Reminders / Notes 原生应用感
- 不要阴影、不要多余装饰
