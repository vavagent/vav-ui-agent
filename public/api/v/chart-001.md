## 设计说明

设计简单柱状图：
- 白底卡片，标题 14px 加粗
- 柱子：flex 布局，不同高度模拟数据
- 当前月高亮蓝色 #3b82f6，其他月浅蓝 #dbeafe
- 底部 X 轴标签 11px 灰色
- 整体风格：通用 Dashboard 柱状图
